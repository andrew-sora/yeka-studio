## 1. RINGKASAN EKSEKUTIF & MODEL BISNIS AGENSI

### A. Konsep Bisnis: "Productized Agency" (Bukan SaaS)
Banyak pemula mengira membuat produk digital harus berupa SaaS (*Software-as-a-Service*) dengan sistem langganan bulanan yang rumit. Dalam kasus SoraDev, model bisnis terbaik adalah **Productized Service / White-Label Template**:
* **Bukan SaaS Multi-Tenant:** Anda tidak perlu pusing mengelola sistem langganan bulanan (*recurring billing*), payment gateway kompleks, atau infrastruktur database terpusat yang rentan crash.
* **Aset Template Berkualitas Tinggi:** Anda membangun 1 basis kode (*codebase*) website eksklusif menggunakan Next.js & Tailwind CSS dengan estetika *luxury editorial* (warna maroon `#120305`, aksen gold `#C9A94B`, dan tipografi Cormorant Garamond).
* **Dijual Putus Berulang Kali:** Website ini disiapkan untuk Yeka Studio sebagai portofolio validasi pertama. Setelah proyek ini sukses, kode yang sama di-kloning dan dijual ke puluhan studio foto lain dengan sedikit penyesuaian (logo, nama, foto portofolio, dan nomor WhatsApp).
* **Margin Keuntungan Sangat Tinggi (>80%):** Karena 90% waktu pembuatan web sudah selesai di depan, biaya pengerjaan untuk klien berikutnya hanya butuh 1–2 hari kerja, namun tetap bisa dijual dengan harga jutaan rupiah.

### B. Kekuatan Penjualan Live Demo (*The Endowment Effect*)
Mayoritas agensi pemula gagal karena menjual konsep abstrak lewat slide presentasi PDF yang membosankan. SoraDev mengambil langkah yang jauh lebih cerdas:
* Anda datang ke Yeka Studio membawa **produk yang sudah 90% jadi memakai karya dan foto mereka sendiri** di alamat `yeka-studio.pages.dev`.
* Secara psikologi bisnis, ini memicu *The Endowment Effect*: pemilik studio merasa website tersebut sudah menjadi milik mereka, sehingga timbul rasa sayang dan enggan jika tidak mengambil penawaran tersebut.

## 2. PENYELESAIAN DEBAT HARGA & TAKTIK "HARGA CORET"

### A. Akar Perdebatan Tim
* **Argumen Teman (Cewek):** *"Harga Rp 850rb - Rp 1,25jt itu terlalu murah!"*  
  * **Fakta:** Dia **BENAR** jika dilihat dari nilai riil pasar. Standar harga pembuatan website custom Next.js + Admin CMS di software house profesional berkisar antara **Rp 3.000.000 s/d Rp 7.000.000**. Kualitas kode dan desain SoraDev memang bernilai jutaan rupiah.
* **Argumen Anda:** *"Tidak apa-apa murah, yang penting dapat klien nyata pertama untuk testimoni SoraDev!"*  
  * **Fakta:** Anda **100% BENAR SECARA STRATEGIS**. Dalam fase awal agensi baru (*Day 1*), aset paling berharga bukanlah margin uang sesaat, melainkan **Bukti Nyata (Social Proof & Case Study)**. Tanpa klien pertama yang puas, klien berikutnya tidak akan percaya. Menurunkan harga adalah taktik *Lowering Entry Barrier* untuk mengunci kesepakatan (*closing*).

### B. Solusi Menang-Menang: Taktik "Harga Coret Pilot Project"
Untuk menjaga nilai brand SoraDev agar tidak dianggap murahan, sekaligus memberi alasan kenapa harganya terjangkau, jangan pernah pasang harga normal langsung murah. Gunakan kemasan **Harga Sponsor / Program Portofolio Perdana**:

```text
PAKET PROFESSIONAL (REKOMENDASI)
Harga Normal    : Rp 2.500.000
Penawaran Pilot : Rp 1.250.000 (Diskon 50%)
*Khusus slot 1 Studio Partner Pertama di Jogja/Solo untuk studi kasus resmi SoraDev.
*Syarat: Bersedia memberikan ulasan testimoni setelah serah terima website.
```

### C. Manfaat Taktik Ini
1. **Menjaga Martabat Brand:** Klien tahu harga aslinya adalah Rp 2,5 juta, sehingga mereka merasa mendapatkan penawaran mewah bernilai tinggi.
2. **Klien Merasa Beruntung (*Lucky Buyer*):** Klien merasa mendapatkan rezeki nomplok karena terpilih dalam program khusus.
3. **Legalitas Meminta Testimoni:** Anda berhak secara profesional meminta video review singkat atau kutipan testimoni karena mereka menerima potongan harga 50%.
4. **Pijakan Menaikkan Harga Nanti:** Untuk klien ke-2 dan ke-3, Anda bisa menaikkan harga ke Rp 1.850.000 lalu Rp 2.500.000 tanpa dicap inkonsisten.

## 3. STRATEGI 3 PAKET (THE RULE OF THREE) & ANATOMI FINANSIAL

### A. Mengapa Wajib 3 Paket (Bukan 2 atau Model Rentang)?
1. **Hindari Model Rentang (Rp 950rb - Rp 1,5jt):** Rentang harga menciptakan ketidakpastian. Klien takut dikenakan harga batas atas dan merasa proses negosiasi berbelit-belit.
2. **Hindari Model 2 Paket (Murah vs Mahal):** Menimbulkan dilema biner (*hitam-putih*). Klien biasanya memilih yang paling murah karena enggan membayar yang termahal.
3. **Kekuatan 3 Paket (*Decoy Effect & Center-Stage Effect*):**
   * **Paket 1 (Starter):** Berfungsi sebagai jangkar (*Anchor*). Memperlihatkan bahwa harga masuk sangat terjangkau.
   * **Paket 2 (Professional ⭐):** Didesain sebagai *Sweet Spot*. Fiturnya melompat jauh dibanding Starter, namun selisih harganya hanya sedikit (Rp 400.000). Secara psikologis, **65%–75% klien akan memilih paket ini**.
   * **Paket 3 (Enterprise):** Berfungsi sebagai jangkar atas (*Premium Decoy*) untuk membuat Paket Professional terasa sangat murah.

## 5. ARSITEKTUR TEKNIS: CLOUDFLARE PAGES & DATABASE SUPABASE

### A. Mengapa Wajib Cloudflare Pages (Bukan Vercel)?
1. **Aturan Lisensi Komersial:**  
   * **Vercel Hobby (Free):** Memiliki klausul *Strictly Non-Commercial*. Jika digunakan untuk menjual website ke klien pihak ketiga secara berbayar, Anda berisiko terkena pelanggaran *Terms of Service*, akun dibekukan, atau dipaksa bayar langganan Pro $20/bulan per user.
   * **Cloudflare Pages (Free):** **100% mengizinkan penggunaan komersial**. Aman, legal, dan bebas risiko tuntutan.
2. **Kinerja & Biaya:**
   * Bandwidth unlimited gratis tanpa batas kuota bulanan.
   * Memiliki data center langsung di Jakarta, membuat akses website super cepat di seluruh jaringan seluler Indonesia.

### B. Memahami Masalah "Local Storage" vs Solusi "Supabase"
* **Kenapa di Local Storage Tidak Sinkron?**  
  `localStorage` hanya menyimpan data di memori aplikasi browser (Google Chrome/Safari) di **satu laptop/HP itu saja**. Jika admin mengedit paket di laptopnya, perubahan tersimpan di laptop tersebut dan **TIDAK PERNAH dikirim ke internet**. Akibatnya, calon pembeli yang membuka website dari HP mereka di rumah tidak akan pernah melihat perubahan harga tersebut.
* **Solusi untuk Paket Professional & Enterprise (Jamstack Architecture):**
  * Website tetap di-hosting sebagai file statis di Cloudflare Pages (`output: "export"`).
  * Data dinamis (paket harga, daftar foto, dan status slot kalender) dipindahkan ke **Supabase** (Database PostgreSQL gratis di cloud).
  * Ketika admin mengedit data dari dashboard, aplikasi memanggil API Supabase via internet.
  * Ketika calon pembeli membuka website, browser mereka mengambil data terbaru langsung dari Supabase secara *real-time* (jeda waktu < 0,5 detik).

```
[ HP ADMIN / LAPTOP ] ────── Mengubah Harga Paket ──────┐
                                                       ▼
                                            ┌──────────────────────┐
                                            │  Cloud DB (Supabase) │
                                            └──────────────────────┘
                                                       ▲
[ HP CALON PEMBELI ] ────── Membuka Website ───────────┘
```

## 6. SOP PEMBAYARAN, SERAH TERIMA & BATASAN MAINTENANCE

### A. Alur Finansial yang Aman (Aturan Emas Agensi)
1. **Down Payment (DP) 50% di Awal:**  
   * Dibayarkan setelah penawaran disepakati dan sebelum tim membeli domain `.com`.
   * **Pantangan:** Jangan pernah mengeluarkan uang pribadi untuk membeli domain sebelum DP klien masuk ke rekening.
2. **Pelunasan 50% di Akhir:**  
   * Dibayarkan setelah demo di domain resmi selesai ditinjau dan disetujui klien.
   * Akses akun dashboard admin dan kredensial domain baru diserahkan setelah uang pelunasan diterima 100%.

### B. Batasan Tegas "Dukungan Perawatan" (Maintenance SLA)
Untuk mencegah klien meminta revisi tak terbatas di luar kesepakatan:

* **TERMASUK (Gratis selama 3 bulan di Paket Pro):**
  1. Bantuan penggantian teks informasi, nomor WA admin, atau penyesuaian harga paket.
  2. Pembaruan 5–10 foto portofolio baru.
  3. Pemantauan teknis agar web tidak down dan form pemesanan WA tetap terhubung lancar.
* **TIDAK TERMASUK (Kena Biaya Tambahan Rp 250.000 – Rp 500.000):**
  1. Perombakan tata letak (*layout*) atau desain visual secara total.
  2. Penambahan fitur baru yang besar (misalnya: integrasi payment gateway Midtrans / Xendit).
  3. Jasa pemotretan atau pengeditan foto klien.
